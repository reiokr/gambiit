# Meridian chess pieces

The SVG files in this directory are the **Meridian** chess piece set by Martin
Sedlák, based on a 1952 German newspaper design and dedicated to the public
domain under **CC0 1.0**.

- Source: https://github.com/kmar/chess_svg_piece_sets
- License: https://creativecommons.org/publicdomain/zero/1.0/
